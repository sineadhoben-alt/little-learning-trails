## Opening script

“We're trying the app, not testing you. There are no marks for this session. Tell me if anything is confusing. You can ask for help or stop whenever you want.”

Give the child time to explore. Avoid pointing to the correct button immediately. When helping, record what you said or did. Never withhold help to generate a failure.

## Suggested tasks

Choose a manageable selection; not every child must complete everything. Include both subjects across the session or across shorter sessions by agreement. Use an activity appropriate to the child's comfort and check required materials/adult support first.

| Task | Neutral prompt | Evidence to observe |
| --- | --- | --- |
| Find an activity | “Choose a Maths activity you would like to try. What do you think you will do?” | Can the child find it and explain the instruction in their own words? |
| Inspect a diagram | “What does this picture tell you? Can you make it easier to see if you want?” | Labels, enlargement, scrolling, connection to the task, access barriers. |
| Recover and use help | If stuck naturally: “What could you try next?” If demonstrating an error deliberately, explain it is a test of the app. | Feedback understood, hint found, retry possible, confidence maintained. Do not force a child to fail. |
| English task | “Choose something to read, write or discuss. Tell me what it asks you to do.” | Reading demand, writing entry, partner needs, comprehension and agency. |
| Resume work | “Leave this unfinished for a moment. Now find it again.” | Child can leave/return and recognise retained work. Adult may conduct restart separately; record who did what. |
| Reflect on work | “How can you tell what you have finished? What would you do next?” | Distinguishes checked answers, reflection and adult review; avoids interpreting counts as test scores. |
| Explore preferences | “What would you choose again? What would you change?” | Voluntary comments on appeal, maturity, imagery and activity variety. No leading praise. |
