# Project handover

Updated 26 September 2026. Product: **Little Learning Trails — Maths & English**, NI P5–P7. Version 0.2.0/build 2 is a supervised-beta candidate, not a public-release approval. Continue in this project; retain IDs and saved records.

## Current provision

62 trails provide 186 anchor tasks with 186 modelled teaching steps and task-specific adult criteria. There are 629 additional practice variants (561 Maths, 68 English), 88 guided projects addressing the review rows, and eight original sustained reading texts. The implementation map and subject action trackers document provision and limits. These quantities do not establish complete curriculum coverage or measured ability.

Project work retains notes, dated writing snapshots, tables, coordinate points and labelled picture compositions locally. Reading predictions can be saved before further text is revealed. Optional synthetic speech reads supplied/revealed text; it is not an expressive human performance or evidence of independent reading. Paper, partner, group and practical tasks still require those real experiences. The app does not observe them automatically.

## Progress and family use

One learner per installation. Siblings can use separate devices independently; there is no family account, shared-device profile switch or cloud synchronisation. Nicknames, draft work, results and project outputs are local. Uninstalling, clearing storage or resetting can remove them. Different browser origins store separately.

TECH-01 is corrected with dense basket counts. The known legacy null-slot representation is repaired narrowly while preserving other records. Invalid records are refused without overwrite or reset. Saving snapshots are queued in order; failures show a retry. Tests cover all basket edit orders, legacy repair, failed reads/writes and retained unrelated work.

Suggestions are topic-specific practice guidance. Moving up requires three distinct recent checked items solved first try without a hint or worked example. Replaying one answer adds no new evidence. Three unsuccessful attempts suggest an easier step. Informal adult feedback guides open anchor tasks; project ratings describe the project and do not change an ability score. No validated or fully adaptive attainment claim is made.

## Adult controls and promotion

A six-digit local PIN gates parent settings, external links and adult ratings. It locks on navigation/background; async completion cannot reopen a dismissed gate. PIN digest and cooldown persist separately from child progress. This is local friction, not identity verification or encryption. There is no account recovery; protect saved learning rather than recommending deletion.

Sinéad Hoben approved the educational approach, drawing on primary/post-primary teaching experience. Individual task approval remains pending. Teacher friends and parent reviewers wish to remain publicly anonymous: use coded records, with relevant expertise verified privately by the owner. Do not imply that AI authors are qualified teachers or an experienced human artistic director.

The source map is in README. Keep content IDs stable. Changes to answers, bank order or learning targets require considering existing drafts/history and reopening affected review decisions. Run typecheck, tests, coverage generation and all-platform export. Native dependencies require prebuild and native builds.
